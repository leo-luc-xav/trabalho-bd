# Dataset - Trabalho de Banco de Dados I

Este documento explica como obter o dataset utilizado no trabalho.

## Dataset utilizado

O trabalho utiliza uma amostra do **Spotify Million Playlist Dataset (MPD)**.

O Million Playlist Dataset foi disponibilizado originalmente pelo Spotify
para o RecSys Challenge 2018 e contém:

- 1.000.000 de playlists;
- mais de 2 milhões de faixas únicas;
- aproximadamente 300 mil artistas.

O dataset original é dividido em arquivos contendo aproximadamente
1.000 playlists cada.

Para o desenvolvimento inicial do trabalho, utilizamos o primeiro
conjunto:

`mpd.slice.0-999.json`

Esse arquivo contém 1.000 playlists.
